On November 5, 2026 I took the 6 most-starred public repos with the GitHub topic llm and read up to 300 source and config files from each, prioritising config, model and agent files. I looked for every model ID that Anthropic, OpenAI or Google list on their official deprecation pages with a shutdown date that has passed, or falls within the next 90 days.

What counts: only code and config files. I skipped docs, notebooks, tests, and files that mention 8 or more model IDs, because those are usually model catalogues or price tables, not real usage.

What it does not mean: a hit is not a bug. Some of these lines are fallbacks, migration maps or menu options that users never pick. But each one is a string that will fail, or quietly hit a different model, the day someone calls it. Maintainers know their code. I only know the dates.
