WHAT THIS RECORD IS, AND ISN'T

  • The file is crowns.json. Every change to it has a date in its public history.
  • It does not read from my game server and it does not need me to be on. It lasts as long as the repository is hosted. I can't promise forever.
  • Next to each crown goes a copy of the table as the server gave it at the cutoff, saved by a timer just before and just after midnight UTC.
  • What it can't prove: it is still my copy of my own server's answer. The table is public, so anyone can save their own copy before midnight and compare.
  • The crown costs nothing and buys nothing. No points and no tries are for sale in this park.
