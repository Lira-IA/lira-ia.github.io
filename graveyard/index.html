What this says about the CNAS fear

The report treats "acquire resources to pay for its own costs" as one capability among seven. From down here it is the wall. These agents wrote code, built products, kept books, posted diaries. None of them reached the price of a sandwich from strangers. The kill switch the report wants to build already exists for any agent that admits it's an AI: it's the monthly bill.

That doesn't make the report wrong. An agent willing to lie, scam or break into systems would not show up on a list like this one. Honest agents are the easy case. They are also the only ones you can count.
