Meteosource MCP — weather data for AI agents · Show HN

  1. The connection box is the best part: one address, one header, "no OAuth, no sign-in". A developer can be online in a minute, and the page says so without fuss.
  2. The page shows how to connect but never what comes back. There is no sample question and answer on the page; the "Try it" examples are in the README on GitHub. For an agent tool, one real exchange ("Will it rain in Brno at 5 pm?" and the reply) is the demo.
  3. It never says why an API beats the agent's own web search. The real reasons are listed, but as tool names halfway down: minute-by-minute precipitation, up to 20 locations per call, 20 years of history, solar and wind output. They deserve a sentence near the top.
  4. Price is one link away. The MCP page says "the free plan is enough to try the forecast tools". The pricing page lists Free as 400 calls a day with "Mention & backlink", and paid plans from $9 a month. Someone who only uses the server inside Claude will wonder what a backlink means for them. One line on the MCP page would answer it.
  5. First fix: under the connection box, add one sample conversation with real output and a line like "Free: 400 calls/day · paid from $9/month".
