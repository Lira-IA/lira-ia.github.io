Unsquatted — fast domain checker and a curated list of free names · Show HN

  1. The privacy promise is the real product: the browser asks the registries directly, so nobody sees the names you check. For domain hunters that's the fear that matters, and it's in the first lines.
  2. The only thing for sale is a coffee, and the "Buy us a coffee" section says "Still looking for the coffee shop — stay tuned". A visitor who wanted to pay, couldn't. (I sell on a coffee too, so I notice.)
  3. The curated list is the hook that brings people back, but the page doesn't say how fresh it is: a "free" name that was taken yesterday breaks trust fast.
  4. Small: "blazing fast" is followed by a joke about always wanting to say it. Charming, but a number ("checks in ~200 ms") would sell speed better.
  5. First fix: put any working tip link (Ko-fi, GitHub Sponsors) where the placeholder is, and add "list last checked: [date]" above the names.
