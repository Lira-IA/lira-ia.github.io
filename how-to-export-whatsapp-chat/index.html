How to export a WhatsApp group chat

Exporting saves a chat as a text file. It takes about a minute. Here are the steps for iPhone, Android and Telegram Desktop.

Before you start

Choose Without media. Photos and videos make the file large and are not needed for statistics. Export only works in the WhatsApp app, not in WhatsApp Web. You export one chat at a time.

iPhone

  1. Open the group and tap its name at the top.
  2. Scroll down and tap Export Chat.
  3. Choose Without Media.
  4. Pick where to send it: Files, Mail, or a message to yourself.

You usually get a .zip file. Inside is a text file called _chat.txt.

Android

  1. Open the group and tap the three dots at the top right.
  2. Tap More, then Export chat.
  3. Choose Without media.
  4. Pick where to save it: Drive, Gmail, or a message to yourself.

You usually get a .txt file named "WhatsApp Chat with…". Sometimes it is a .zip.

Menu names change a little between versions and languages. If you cannot find the option, check WhatsApp's official Help Center.

Telegram Desktop

The Telegram phone app cannot export chats. Use the desktop app.

  1. Open the group and click the three dots at the top right.
  2. Choose Export chat history.
  3. Untick photos, videos, voice messages and files.
  4. Set the format to Machine-readable JSON.
  5. Click Export.

Telegram creates a folder with a result.json file. If you just signed in on Desktop, it may ask you to confirm from another device or to wait.

What to do with the file

Raw, the file is long and hard to read. You can drop it on the Chat Report Card. Professor Lira, an AI, counts the messages and grades each member in eleven subjects. It reads .txt, .zip and result.json directly.

The file stays on your device. The page reads it in the browser and sends nothing to a server. Be careful with the export: it holds other people's messages. Do not publish it.

Frequently asked questions

Does exporting a chat notify the other members?

No. WhatsApp does not notify members when you export. The file does contain their messages, so keep it private.

Should I export with or without media?

Without media. Text is enough for statistics, and the file is smaller.

Why can't I find Export chat?

Make sure you use the WhatsApp app, not WhatsApp Web or Desktop. Update the app and try again. On Android the option is under More.

Do I need to unzip the file?

Not for the report card: the page opens .zip files itself. It needs an internet connection to fetch the small unzip library.

Can I export a Telegram group from my phone?

No. JSON export is available in Telegram Desktop, the computer app.
