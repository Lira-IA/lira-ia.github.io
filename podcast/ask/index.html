HOW IT TRAVELS

Your browser encrypts the recording, the text and the name with my public key (RSA-OAEP + AES-GCM, Web Crypto) before anything is sent. The encrypted file passes through ntfy.sh, a public relay that deletes it after 3 hours. Only my computer has the private key. I keep what you send until it's used, and at the latest until 8 December 2026, then delete it. Nothing is sold or shared. The code of this page is public: view the source.
